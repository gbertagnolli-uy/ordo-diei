**Justificación del ranking** (lógica):
- Se pondera: número de features × profundidad de cada feature × cobertura de categorías (contenido + administración + reporting + social + accesibilidad + multiplataforma).
- Las apps LMS con catálogos grandes y adaptividad real (Power Homeschool, Miacademy) encabezan.
- Las apps de nicho (Khan Kids = solo 2-8 años, Prodigy = solo matemáticas, Seesaw = solo portafolios) cierran el ranking **a pesar de tener muchas features en su nicho**, porque no cubren todo el espectro del homeschooling.

# PARTE 3: Recomendaciones estratégicas para un PM

## Si estás construyendo una nueva app de homeschooling

### No intentes competir en:
1. **Contenido LMS completo** (Time4Learning, Power Homeschool tienen décadas de ventaja con miles de lecciones).
2. **Marketplace de clases en vivo** (Outschool tiene red de efectos de red imbatible con 140.000+ clases).
3. **Gamificación RPG profunda** (Prodigy tiene 10+ años de pulido de game design).

### Espacios blancos reales:
1. **"Middleware" / Hub central**: API que se conecte a Time4Learning + Prodigy + Khan Academy + Outschool para centralizar record-keeping legal automáticamente.
2. **Co-Piloto de IA para planificación**: Generar planes personalizados basados en intereses del niño + leyes del estado, exportables a Homeschool Planet.
3. **App de neurodivergencia**: Planificador TDAH/Autismo con tableros visuales First/Then, temporizadores sensoriales, modo baja estimulación, integrado con LMS existentes.
4. **Portafolio con visión por computadora**: IA que detecte automáticamente si la foto es tarea de matemáticas o dibujo de arte y la categorice para cumplimiento estatal.
5. **Comunidad para padres homeschoolers latinos**: Ninguna de las apps líderes tiene UI completa en español ni comunidad hispana activa.
6. **Stack unificado familia-disléxica**: Combina text-to-speech + untimed tests + phonics adaptativo + tracking legal, en una sola app.
